# 📈 Stock Viewer 

A simple and clean web application that fetches real-time stock data and allows users to search and filter stocks easily.

---

## 🚀 Features

* 📡 Fetch stock data using a public API
* 🔎 Search stocks by name
* 🎛️ Filter stocks based on price
* 🔄 Dynamic UI updates
* 🎨 Clean and minimal user interface

---

## 🛠️ Tech Stack

* Frontend: React.js
* Styling: CSS / Tailwind CSS
* API: Alpha Vantage / Finnhub

---

## 📷 How It Works

1. The app fetches stock data from an API
2. The data is stored in state
3. Users can search for stocks using the search bar
4. Users can filter stocks based on price
5. The UI updates instantly based on user input

---



## 🎯 Project Goal

This project is built as a beginner-friendly application to practice:

* API integration
* Array filtering
* Search functionality
* UI design
